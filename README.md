# Аренда инструмента

Личное mobile-first PWA для учёта аренды инструмента.

## Как пользоваться

Откройте опубликованную GitHub Pages-ссылку в Chrome на Android и в меню браузера выберите «Установить приложение». Данные инструментов, клиентов, аренд и бронирований сохраняются только в IndexedDB этого устройства. Интернет, учётная запись, сервер и оплата не нужны.

Не очищайте данные Chrome и не удаляйте приложение, пока не появится отдельная функция резервной копии: это удалит локальные записи.

## Разработка

`pnpm install` → `pnpm dev` запускает PWA локально. При отправке в ветку `main` GitHub Actions публикует приложение на GitHub Pages.

Материалы в `sources/` не используются и не изменяются.
